## ✦ Overview

Velvet Labs Ltd. is a modern digital agency specializing in high-performance web engineering, luxury brand identity, and scalable growth architecture. This repository hosts the official single-page portfolio application featuring real-time 3D geometry and responsive styling.

### Key Highlights
- **Interactive 3D Canvas:** Lightweight Three.js scene with kinetic velvet-inspired geometry, particle dust, and cursor-reactive parallax motion.
- **Minimalist Luxury Aesthetic:** Curated typography pairing (*Cormorant Garamond* & *Plus Jakarta Sans*), champagne-gold metallic accents, and glassmorphic depth.
- **Client Conversion Triggers:**
  - One-click Gmail composition trigger.
  - Direct WhatsApp chat link (`+91 97129 17179`).
  - Google Form client onboarding gateway with popup-blocker fallbacks.
- **Cross-Platform & Responsive:** Built mobile-first with zero heavy framework bloat.
